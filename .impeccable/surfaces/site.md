Scope: the Closeup docs site in `site/` (Blume). Landing page is Persuade; every docs page is Read.

Audience: Mac users with an Android phone who want it as a webcam, most of whom don't know adb, scrcpy or OBS. A short developer section covers building and internals.

## Direction contract

seed: Harsha picked "warm gray and signal orange" and "neutral grotesk" after rejecting plum and sunset with Nunito.

THESIS: The site looks like a piece of plain, well-made hardware: warm stone grays with a single orange used only where it means something. It refuses the plum-and-sunset palette and rounded display type of the first pass.

OWN-WORLD: Warm gray ground (#F2F0EC light, #1A1917 dark), dark warm ink, one signal orange (#E8590C / #F06418) for the main button and one highlight per view, and a burnt orange (#B8420A) for links in light mode. Geist for everything, Geist Mono for small technical readouts. Real macOS screenshots with soft warm shadows.

STORY: A visitor reads the three steps, sees what it is in one sentence, skims four short points beside the real Live Controls panel, opens a question or two, then goes to Install or the docs. Copy stays extremely minimal.

FIRST VIEWPORT: The type poster. Three huge Geist lines, "Plug in your phone. Click Start Webcam. Pick OBS Virtual Camera.", with the two on-screen names in the accent. Under a heavy rule: the icon, one sentence, a dark Get started pill and a Read the docs link.

FORM: Persuade landing on PageLayout, then Blume's three-column docs for Read pages, themed through tokens only. Below the fold: four bullet points with the Live Controls screenshot, then a short FAQ in native details/summary.

SIGNATURE: The three-line poster headline that is also the whole setup.
